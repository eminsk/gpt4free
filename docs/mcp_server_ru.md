# gpt4free MCP (Model Context Protocol) Сервер

## Обзор

MCP сервер gpt4free предоставляет реализацию стандарта Model Context Protocol, позволяя AI ассистентам использовать возможности gpt4free через стандартизированные интерфейсы.

MCP сервер предоставляет AI ассистентам возможности:
- Веб-поиск
- Веб-скрапинг
- Генерация изображений
- Преобразование текста в аудио
- Конвертация URL в формат markdown
- Генерация кода

## Установка

Для использования MCP сервера установите gpt4free с необходимыми зависимостями:

```bash
pip install gpt4free
# или
uv pip install gpt4free
```

Для полной функциональности установите все зависимости:

```bash
pip install gpt4free[all]
# или
uv pip install gpt4free[all]
```

## Запуск сервера

### Использование CLI команды

MCP сервер можно запустить с помощью встроенной команды:

```bash
g4f-mcp --http --port 8765
```

### Использование скрипта

Альтернативно, можно использовать предоставленный скрипт:

```bash
python scripts/start_mcp_server.py --port 8765
```

### Доступные опции

- `--http`: Запуск сервера в HTTP режиме (по умолчанию: True)
- `--host`: Хост для привязки HTTP сервера (по умолчанию: 0.0.0.0)
- `--port`: Порт для привязки HTTP сервера (по умолчанию: 8765)
- `--origin`: URL источника для запросов (опционально)

## Эндпоинты

После запуска сервер предоставляет следующие эндпоинты:

- **MCP эндпоинт**: `http://0.0.0.0:8765/mcp` - Основной MCP JSON-RPC эндпоинт
- **Проверка состояния**: `http://0.0.0.0:8765/health` - Проверка состояния сервера

## Доступные инструменты

### Веб-поиск

- **Название**: `web_search`
- **Описание**: Поиск в интернете с использованием DuckDuckGo. Возвращает результаты поиска с заголовками, URL и фрагментами.
- **Параметры**:
 - `query` (обязательный): Поисковый запрос для выполнения
  - `max_results` (опциональный): Максимальное количество возвращаемых результатов (по умолчанию: 5)
 - `region` (опциональный): Регион поиска (по умолчанию: en-us)

### Веб-скрапинг

- **Название**: `web_scrape`
- **Описание**: Извлечение и извлечение текстового содержимого с веб-страницы. Возвращает очищенное текстовое содержимое с опциональным ограничением по количеству слов.
- **Параметры**:
 - `url` (обязательный): URL веб-страницы для скрапинга
  - `max_words` (опциональный): Максимальное количество слов для извлечения (по умолчанию: 100)

### Генерация изображений

- **Название**: `image_generation`
- **Описание**: Генерация изображений из текстовых подсказок с использованием AI. Возвращает URL сгенерированного изображения.
- **Параметры**:
 - `prompt` (обязательный): Текстовое описание генерируемого изображения
  - `model` (опциональный): Используемая модель генерации изображений (по умолчанию: flux)
  - `width` (опциональный): Ширина изображения в пикселях (по умолчанию: 1024)
  - `height` (опциональный): Высота изображения в пикселях (по умолчанию: 1024)

### Текст в аудио

- **Название**: `text_to_audio`
- **Описание**: Генерация аудио URL из текстовой подсказки с использованием сервиса text-to-speech от Pollinations AI. Возвращает прямой URL к сгенерированному аудиофайлу.
- **Параметры**:
 - `prompt` (обязательный): Текстовая подсказка для аудио модели (например: 'Read this: Hello, world!')
  - `voice` (опциональный): Голос для text-to-speech (по умолчанию: 'alloy')
  - `url_encode` (опциональный): Кодировать ли текст подсказки в URL (по умолчанию: True)

### MarkItDown

- **Название**: `mark_it_down`
- **Описание**: Конвертация URL в формат markdown с использованием MarkItDown. Поддерживает HTTP/HTTPS URL и возвращает отформатированное markdown содержимое.
- **Параметры**:
  - `url` (обязательный): URL для конвертации в формат markdown (должен быть HTTP/HTTPS)
  - `max_content_length` (опциональный): Максимальная длина содержимого для обработки (по умолчанию: 10000)

### Генерация кода

- **Название**: `code_generation`
- **Описание**: Генерация кода на основе текстовой подсказки с использованием AI. Поддерживает различные языки программирования и фреймворки. Возвращает сгенерированный код.
- **Параметры**:
  - `prompt` (обязательный): Текстовое описание генерируемого кода
  - `model` (опциональный): Используемая модель AI для генерации кода (по умолчанию: gpt-4o)
  - `language` (опциональный): Язык программирования для генерируемого кода (по умолчанию: python)
  - `max_tokens` (опциональный): Максимальное количество токенов для генерации (по умолчанию: 2048)

### Чтение файлов

- **Название**: `file_read`
- **Описание**: Чтение содержимого файла из файловой системы. Возвращает содержимое файла в виде текста.
- **Параметры**:
  - `path` (обязательный): Путь к файлу для чтения
  - `max_size` (опциональный): Максимальный размер файла для чтения в байтах (по умолчанию: 1048576 = 1MB)

### Запись файлов

- **Название**: `file_write`
- **Описание**: Запись содержимого в файл в файловой системе. Создает или перезаписывает файл с указанным содержимым.
- **Параметры**:
  - `path` (обязательный): Путь к файлу для записи
  - `content` (обязательный): Содержимое для записи в файл
  - `overwrite` (опциональный): Перезаписывать ли существующий файл (по умолчанию: true)

### Листинг файлов

- **Название**: `file_list`
- **Описание**: Список файлов и каталогов в указанном каталоге. Возвращает информацию о каждом элементе, включая тип и размер.
- **Параметры**:
  - `path` (обязательный): Путь каталога для листинга
  - `recursive` (опциональный): Рекурсивно ли перечислять файлы (по умолчанию: false)
  - `max_items` (опциональный): Максимальное количество возвращаемых элементов (по умолчанию: 100)

### Выполнение кода

- **Название**: `code_execute`
- **Описание**: Выполнение фрагментов Python кода в безопасной среде subprocess. Возвращает вывод выполнения кода.
- **Параметры**:
  - `code` (обязательный): Python код для выполнения
  - `timeout` (опциональный): Таймаут выполнения в секундах (по умолчанию: 10)

- **Название**: `code_execute_safe`
- **Описание**: Выполнение фрагментов Python кода в ограниченной среде с использованием анализа AST. Возвращает вывод выполнения кода.
- **Параметры**:
 - `code` (обязательный): Python код для выполнения в ограниченной среде

### Операции с базой данных
- **Название**: `database`
- **Описание**: Выполнение SQL запросов к SQLite базам данных. Поддерживает операции SELECT, INSERT, UPDATE, DELETE. Возвращает результаты запроса или статус выполнения.
- **Параметры**:
 - `db_path` (обязательный): Путь к файлу SQLite базы данных
 - `query` (обязательный): SQL запрос для выполнения
  - `params` (опциональный): Параметры для SQL запроса

### HTTP запросы
- **Название**: `http_request`
- **Описание**: Отправка HTTP запросов (GET, POST, PUT, DELETE) на внешние эндпоинты. Поддерживает заголовки, параметры запроса и тело запроса. Возвращает данные ответа.
- **Параметры**:
  - `url` (обязательный): URL для отправки HTTP запроса
 - `method` (опциональный): HTTP метод (GET, POST, PUT, DELETE) (по умолчанию: GET)
  - `headers` (опциональный): HTTP заголовки для включения в запрос
  - `params` (опциональный): Параметры запроса для включения в запрос
  - `body` (опциональный): Тело запроса для POST/PUT запросов
  - `timeout` (опциональный): Таймаут запроса в секундах (по умолчанию: 30)

## Методы протокола MCP

Сервер поддерживает следующие методы протокола MCP:

- `initialize`: Инициализация сессии MCP
- `tools/list`: Список всех доступных инструментов
- `tools/call`: Вызов конкретного инструмента с параметрами
- `ping`: Метод проверки состояния

## Пример использования

Вот пример вызова инструмента веб-поиска с использованием curl:

```bash
curl -X POST http://0.0.0:8765/mcp \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "web_search",
      "arguments": {
        "query": "gpt4free библиотека",
        "max_results": 3
      }
    }
  }'
```

## Интеграция с AI ассистентами

MCP сервер может быть интегрирован с AI ассистентами, поддерживающими стандарт Model Context Protocol, позволяя им использовать возможности gpt4free стандартным способом.

## Устранение неполадок

- Убедитесь, что все необходимые зависимости установлены, особенно `aiohttp` для HTTP транспорта
- Убедитесь, что указанный порт не используется другим процессом
- Проверьте, что ваш брандмауэр разрешает подключения к указанному порту
